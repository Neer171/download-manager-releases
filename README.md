# Download Manager: installers

Download the installer for your computer from the **[Releases](../../releases/latest)** page:

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1–M4) | `Download-Manager-<version>-AppleSilicon.dmg` |
| Mac with Intel | `Download-Manager-<version>-Intel.dmg` |
| Windows 10/11, 64-bit | `Download-Manager-Setup-<version>.exe` |
| Firefox extension | `Download-Manager-Firefox-<version>.zip` |

The installers include everything, so installing works offline. `README.txt` in each release has step-by-step instructions.

From version 1.3.0 on, installed apps update themselves from this page. Every release includes `latest.json`, signed with Download Manager's update key; apps install an update only if that signature and the installer's checksum are valid.

This repository holds installers only.
